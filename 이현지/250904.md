## 빅데이터 분석 워크플로우
### 1단계: 원시 데이터 확보 및 HDFS 업로드
먼저 데이터를 파일 형태로 다운로드 함. 
- HDFS 디렉토리 생성:
분석을 위해 데이터를 저장할 HDFS 디렉토리 생성. 데이터 관리를 위해 년/월/일과 같은 계층 구조를 사용.
- 데이터 업로드:
로컬에 있는 파일을 HDFS로 업로드. 이 과정을 통해 로컬에 있던 대용량 데이터가 하둡 분산 파일 시스템에 안전하게 저장됨.

### 2단계: 스파크를 이용한 데이터 분석
하둡에 저장된 데이터를 스파크 애플리케이션으로 읽고 분석함.
- 데이터 로드
- 데이터 분석 및 처리: 데이터 로드 후, 스파크의 다양한 기능을 활용해 복잡한 분석을 수행.

### 3단계: 분석 결과 저장
스파크로 분석한 최종 결과를 서비스에서 사용할 수 있도록 데이터베이스에 저장.
- 결과 저장: 스파크 데이터 프레임의 분석 결과를 JDBC를 통해 데이터베이스에 저장.
