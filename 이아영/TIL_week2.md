### 기술

📱 앱 개발 / 기술 학습

- What I learned

  - 모바일 앱 개발 용어 차이

  1. 웹앱 (Web App)

  - 정의: 앱처럼 보이지만 실제로는 브라우저에서 동작하는 웹사이트.
  - 특징:
    앱스토어 설치 불필요 → URL로 접속
    업데이트는 서버에서 즉시 반영됨 (사용자는 새로고침만 하면 됨)
    카메라, GPS 같은 디바이스 기능 접근은 제한적
  - 예시: 네이버 모바일 페이지, Gmail 웹버전, Twitter 웹버전

  2. 하이브리드 앱 (Hybrid App)

     - 정의: 웹 기술(HTML, CSS, JS)로 만든 후, 네이티브 앱 껍데기 안에 넣어 실행하는 방식.
     - 특징:
       앱스토어에서 설치 가능
       내부적으로는 **웹뷰(WebView)**를 사용 → 사실상 웹이지만 앱처럼 보임
       플러그인을 통해 카메라, GPS, 푸시 알림 등 네이티브 기능 일부 사용 가능
       성능은 네이티브 앱보다 떨어질 수 있음
       대표 프레임워크: Ionic, Cordova, PhoneGap
     - 예시: 초창기 카카오톡 일부 기능, 배달의민족 초창기 버전

  3. 네이티브 앱 (Native App / Mobile App)

     - 정의: iOS, Android 각각의 운영체제 전용 언어와 SDK로 개발한 앱.
     - 특징:
       OS 최적화 → 성능/속도가 가장 뛰어남
       카메라, GPS, 블루투스, 센서 등 모든 디바이스 기능 100% 활용 가능
       앱스토어에서 설치 필요
       플랫폼별 코드 따로 관리해야 함 (iOS는 Swift/Objective-C, Android는 Kotlin/Java)
     - 예시: 인스타그램, 카카오뱅크, 토스

  4. 크로스플랫폼 앱 (Cross-Platform) ← 요즘 많이 쓰는 것

     - 정의: 한 번의 코드로 iOS/Android 앱을 동시에 개발 가능.
     - 특징:
       웹앱/하이브리드보다 성능이 좋고, 네이티브와 유사한 경험 제공
       네이티브 기능도 플러그인으로 대부분 사용 가능
       코드 재사용률 높음 → 유지보수 효율적
       대표 프레임워크: React Native, Flutter
     - 예시: 넷플릭스, 에어비앤비 일부 기능

  - 모바일 앱 개발 기초
    - React Native와 Flutter의 차이:
      - React Native → JS/React 기반, 웹 개발자 친화적
      - Flutter → Dart 기반, 위젯 단위, 안정된 성능/일관된 UI
  - 웹 ↔ 앱 개발 프로세스 차이
    - 웹은 브라우저 기반 배포, 앱은 스토어 배포 과정 필요
    - DB는 서버 공용 사용 가능 (앱/웹 차이는 클라이언트 UI & 배포 구조 차이)
  - 하이브리드 개발
    - Spring Boot(백엔드) + React/React Native(프론트/앱) 조합 가능

- Questions I asked

  - 모바일 개발을 처음 시작할 때 React Native vs Flutter 중 무엇을 선택하는 게 좋을까?
  - 웹 개발 경험이 있는데, 앱 개발은 프로세스가 많이 다른가?
  - 데이터베이스는 웹/앱 각각 별도로 구축해야 하나, 아니면 공용 서버로 가능할까?

- Insights
  - 기존에 배운 React 지식이 있다면 React Native도 좋은 출발점.
