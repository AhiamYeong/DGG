## 1. 증분 적재(월 단위 INSERT/OVERWRITE)

### 개념

새 CSV가 `s3://$RAW_BUCKET/bus_monthly/`에 추가되면 **그 월(예: 202508)** 만 Curated에 반영합니다.

### 목적

전체 재처리 없이 **빠르고 멱등적인 월 단위 갱신**.

### 방법(Athena SQL)

**Path A) RAW 테이블이 이미 존재(`$RAW_DB.$RAW_TABLE`) 하는 경우**

```sql

TBLPROPERTIES ('skip.header.line.count'='1');  -- 파일마다 헤더 1줄이면 스킵

-- 2) INSERT (col 매핑)

    col27 AS in10, col28 AS out10, col29 AS in11, col30 AS out11,
    col31 AS in12, col32 AS out12, col33 AS in13, col34 AS out13,
    col35 AS in14, col36 AS out14, col37 AS in15, col38 AS out15,
    col39 AS in16, col40 AS out16, col41 AS in17, col42 AS out17,
    col43 AS in18, col44 AS out18, col45 AS in19, col46 AS out19,
    col47 AS in20, col48 AS out20, col49 AS in21, col50 AS out21,
    col51 AS in22, col52 AS out22, col53 AS in23, col54 AS out23
  FROM $RAW_DB.$RAW_TABLE_NOHEADER
  WHERE regexp_replace(col0,'[^0-9]','') = '202508'
),
expanded AS (
  SELECT 'bus' AS mode, ym, h AS hour,
         line_id, line_no, line_name, station_id, ars_id, station_name,
         CAST(i AS BIGINT) AS in_cnt_m, CAST(o AS BIGINT) AS out_cnt_m
  FROM src
  CROSS JOIN UNNEST(
    SEQUENCE(0,23),
    ARRAY[in00,in01,in02,in03,in04,in05,in06,in07,in08,in09,in10,in11,in12,in13,in14,in15,in16,in17,in18,in19,in20,in21,in22,in23],

  ) AS t(h,i,o)
)
SELECT mode, ym, hour, line_id, line_no, line_name, station_id, ars_id, station_name,
       GREATEST(0,in_cnt_m) AS in_cnt_m, GREATEST(0,out_cnt_m) AS out_cnt_m,
       (GREATEST(0,in_cnt_m)+GREATEST(0,out_cnt_m)) AS total_flow_m
FROM expanded;
```

### 주의점

* 멱등성: 같은 월을 반복 실행해도 **중복**이 안 생기도록 스테이징→스왑(또는 OVERWRITE) 전략을 사용합니다.
* RAW 헤더/인코딩이 애매하면 **Path B**가 안전합니다.

## 2. 오케스트레이션(자동화)

### 개념/목적

**S3 업로드 → 자동 INSERT/CTAS → 알림**의 표준 루프를 구성합니다.

### 방법(구성 예)

1. **EventBridge 규칙**:

   * 이벤트 소스: `aws.s3`
   * 이벤트 패턴: `Object Created` + `bucket.name = $RAW_BUCKET`, `object.key` prefix=`bus_monthly/`
2. **Lambda**: 업로드 키에서 `ym` 파싱 → 위 INSERT 쿼리 실행
3. **SNS/Slack**: 성공/실패 알림

**Lambda 파이썬(요지, Workgroup=primary)**

```python
import boto3, urllib.parse, os, re
athena = boto3.client('athena', region_name=os.environ['REGION'])

def handler(event, context):
    key = urllib.parse.unquote_plus(event['Records'][0]['s3']['object']['key'])
    # 예: bus_monthly/2025년_..._(08월).csv -> 202508 으로 치환
    m = re.search(r'(\d{4}).*?\((\d{2})월\)', key)
    ym = f"{m.group(1)}{m.group(2)}" if m else None
    if not ym: return {"ok": False, "reason": f"ym parse fail: {key}"}

           i AS in_cnt_m, o AS out_cnt_m, (i+o) AS total_flow_m
    FROM {os.environ['RAW_DB']}.{os.environ['RAW_TABLE']}
    CROSS JOIN UNNEST(
      SEQUENCE(0,23),
      ARRAY["00시승차총승객수","1시승차총승객수","2시승차총승객수","3시승차총승객수","4시승차총승객수","5시승차총승객수","6시승차총승객수","7시승차총승객수","8시승차총승객수","9시승차총승객수","10시승차총승객수","11시승차총승객수","12시승차총승객수","13시승차총승객수","14시승차총승객수","15시승차총승객수","16시승차총승객수","17시승차총승객수","18시승차총승객수","19시승차총승객수","20시승차총승객수","21시승차총승객수","22시승차총승객수","23시승차총승객수"],
```

## 7. Spark 처리(두 경로)

### 7-A. EMR Serverless(Spark) — 서버리스 경로

1. EMR Serverless에서 **Spark 앱** 생성(역할에 S3 입출력 권한 부여)
2. 아래 스크립트를 S3에 업로드: `s3://transit-raw-test250902/code/bus_to_parquet.py`
3. Submit Job(입력/출력 경로 파라미터 지정)

**`bus_to_parquet.py`(요지)**

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, regexp_replace, expr

RAW="s3a://transit-raw-test250902/bus_monthly/*.csv"
OUT="s3a://transit-curated-test250902/bus_hourly/"

spark = SparkSession.builder.appName("bus_to_parquet").getOrCreate()
df = (spark.read.option("header","true").csv(RAW))

# wide -> long : Day1과 동일 아이디어(시간 0..23 펼치기)
cols_in = [f"{h}시승차총승객수" for h in range(24)]
cols_out= [f"{h}시하차총승객수" for h in range(24)]

src = (df.select(
        regexp_replace(col("사용년월"), r"[^0-9]", "").alias("ym"),
        col("노선ID").alias("line_id"),
        col("노선번호").alias("line_no"),
        col("노선명").alias("line_name"),
        col("표준버스정류장ID").alias("station_id"),
        col("버스정류장ARS번호").alias("ars_id"),
        col("역명").alias("station_name"),
        *[col(c).alias(f"in{h:02d}") for h,c in enumerate(cols_in)],
        *[col(c).alias(f"out{h:02d}") for h,c in enumerate(cols_out)]
      ))

long = None
for h in range(24):
    part = (src.select("ym","line_id","line_no","line_name","station_id","ars_id","station_name")
                 .withColumn("hour", expr(str(h)))
                 .withColumn("in_cnt_m",  col(f"in{h:02d}").cast("bigint"))
                 .withColumn("out_cnt_m", col(f"out{h:02d}").cast("bigint")))
    long = part if long is None else long.unionByName(part)

long = long.selectExpr(
    "'bus' as mode","ym","hour","line_id","line_no","line_name",
    "station_id","ars_id","station_name",
    "greatest(0,in_cnt_m) as in_cnt_m",
    "greatest(0,out_cnt_m) as out_cnt_m",
    "(greatest(0,in_cnt_m)+greatest(0,out_cnt_m)) as total_flow_m"
)

(long.write.mode("overwrite")
     .partitionBy("ym","hour")
     .parquet(OUT))
```

**주의**

* 잡 역할에 **S3 입출력(두 버킷)**, (KMS 사용 시) `kms:Decrypt` 권한 필요.
* EMR은 `s3a://` 사용.
