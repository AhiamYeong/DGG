# 피로도 기반 경로 추천 서비스

## 서비스 소개

- 서비스명: 덜낑김
- 팀명: 윤밀원
  - 팀원: 이현지(팀장), 김현재, 박승규, 장민석, 이아영, 주연우
- 한 줄 소개: 피로도 기반 경로 추천 서비스

### 기술 소개

- FE: React Native, TypeScript
- BE: Spring Boot, Kafka, Hadoop, Spark
- DB: MySQL, Redis
- INFRA: Ubuntu, Docker, EC2, Nginx
- CI/CD: Jenkins

## 서비스 설명

- 이 서비스는 **사용자의 피로도**를 기반으로 최적의 경로와 모임 장소를 추천해주는 모바일 애플리케이션입니다.
- 피로도는 **삼성 헬스**와의 연동을 통해 개인 맞춤형으로 제공됩니다.
- 기존의 **최단 경로, 최소 환승 중심** 길찾기 서비스에서 한 단계 발전하여, **날씨 및 개인의 과거 이동 데이터**를 활용해 피로도를 최소화하는 새로운 경로를 제공합니다.
- 모임 상황에서는 **피로도를 고려한 장소 및 해산 시간** 추천 기능을 포함하고 있습니다.

## 주요 기능

### 1. 개인 경로 추천 서비스

- **피로도가 가장 낮은 경로 추천**:
  경로 내 혼잡도, 날씨, 사용자의 설문 등을 바탕으로 피로도가 낮은 경로를 맞춤형으로 추천합니다.

- **최단 경로 및 최소 환승 경로 제공**:
  기존 길찾기 서비스의 핵심 기능을 기본적으로 제공합니다.

- **사용자 맞춤형 알림 서비스**:

  - **자야 돼 챌린지**: 권장 취침 시간 알림을 통해 피로도 관리에 게이미피케이션 요소를 더합니다.
  - **출발 시간 알림**: 약속 시간과 피로도를 고려해 적절한 출발 시간을 알려줍니다.
  - **집 가는 시간 알림**: 막차 시간 등을 고려해 적절한 귀가 시간을 알려줍니다.

- **다중 경유지 계산**:
  여러 경유지를 거쳐야 할 경우, 피로도를 최소화하는 최적 방문 순서를 계산하여 경로를 제공합니다.

### 2. 개인의 피로도 관리

- **일상 피로도 관리**:
  삼성 헬스 SDK와 연동하여, 캐릭터화하여 직관적으로 개인의 피로도 관리에 도움을 줍니다.

- **피로도 통계**:
  피로도를 게이지로 시각화하고, 피로도에 영향을 미치는 요인들을 통계로 제공합니다.

- **사용자 설문을 통한 피로도 요인 조사**:
  개인 맞춤형 피로도 계산을 위해, 사용자에게 설문을 받아 피로도에 영향을 미치는 요인을 결정합니다.

### 3. 약속(장소) 추천 서비스

- **피로도 기반 장소 추천**:

  - **모두에게 덜 피로한 장소**: 모임원 현재 위치 기준, 이동 피로도가 가장 낮은 장소를 추천합니다.
  - **과거 데이터 기반 추천**: 이번에 a, b의 피로도가 낮은 장소였다면 다음은 c의 피로도가 더 낮은 장소로 추천합니다.

- **피로도 기반 해산 시간 알림**:
  - **모두가 덜 피로하게 귀가할 수 있는 시간**: 막차 시간, 대중교통 배차 간격 등을 반영하여 해산 시간을 추천합니다.
  - **상황별 세분화**: “몇 명 먼저 귀가”, “막차 이슈” 등 다양한 상황을 고려한 맞춤 알림을 제공합니다.
