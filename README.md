# 피로도 기반 경로 추천 서비스

이 서비스는 **사용자의 피로도**를 기반으로 최적의 경로와 모임 장소를 추천해주는 웹 애플리케이션입니다.  기존의 **최단 경로, 최소 환승 중심** 길찾기 서비스에서 한 단계 발전하여, **날씨 및 개인의 과거 이동 데이터**를 활용해 피로도를 최소화하는 새로운 경로를 제공합니다.  
또한, 모임 상황에서는 **피로도를 고려한 장소 및 해산 시간** 추천 기능을 포함하고 있습니다.

## 주요 기능

### 1. 개인 경로 추천 서비스
- **최단 경로 및 최소 환승 경로 제공**  
  기존 길찾기 서비스의 핵심 기능을 기본적으로 제공합니다.

- **피로도 기반 경로 추천 알고리즘**  
  날씨와 같은 환경적 요소를 고려하여 피로도가 낮은 경로를 추천합니다.

- **사용자 맞춤형 알림 서비스**
  - **자야 돼 챌린지**: 권장 취침 시간 알림을 통해 피로도 관리에 게이미피케이션 요소를 더합니다.
  - **출발 시간 알림**: 약속 시간과 피로도를 고려해 적절한 출발 시간을 알려줍니다.
  - **집 가는 시간 알림**: 막차 시간 등을 고려해 적절한 귀가 시간을 알려줍니다.

- **출/도착 토글 전환**  
  피로도 기준 최적 경로 중심으로 출발지와 도착지를 간편하게 전환할 수 있습니다.

- **다중 경유지 계산**  
  여러 경유지를 거쳐야 할 경우, 피로도를 최소화하는 최적 방문 순서를 계산하여 경로를 제공합니다.


### 2. 모임 추천 서비스
- **피로도 기반 장소 추천**
  - **모두에게 덜 피로한 장소**: 모임원 현재 위치 기준, 이동 피로도가 가장 낮은 장소를 추천합니다.
  - **과거 데이터 기반 추천**: 이번에 a, b의 피로도가 낮은 장소였다면 다음은  c의 피로도가 더 낮은 장소로 추천합니다.
- **피로도 기반 해산 시간 알림**
  - **모두가 덜 피로하게 귀가할 수 있는 시간**: 막차 시간, 대중교통 배차 간격 등을 반영하여 해산 시간을 추천합니다.
  - **상황별 세분화**: “몇 명 먼저 귀가”, “막차 이슈” 등 다양한 상황을 고려한 맞춤 알림을 제공합니다.

- **출/도착 토글 전환**  
  모임 종료 후 개인 경로 페이지로 이동하여 귀가 경로를 쉽게 확인할 수 있습니다.


## 추가 기능

- **HP 게이미피케이션**  
  피로도를 HP(Health Point)로 시각화합니다. 이동 시간에 따라 HP가 감소하는 애니메이션을 통해 직관적으로 피로도를 인지할 수 있습니다.

- **개인 기록**  
  사용자의 **이전 경로 기록**을 저장하고 분석하여, 더 정교하고 맞춤화된 추천을 제공합니다.
