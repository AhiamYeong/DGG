# 맵리듀스 알고리즘 - 인버티드 인덱스
## 1. 인버티드 인덱스란?
### 인버티드 인덱스
인버티드 인덱스는 **특정 단어(Term)가 어떤 문서(Document)에 나타나는지**에 대한 정보를 담고 있는 데이터 구조  
**단어 → 문서 ID 목록** 형태로 구성

- 사용자가 특정 단어를 검색했을 때, 모든 문서를 일일이 스캔하는 대신 인버티드 인덱스에서 단 한 번의 조회(Lookup)만으로 해당 단어를 포함하는 모든 문서를 순식간에 찾아낼 수 있다.

인버티드 인덱스의 두 가지 유소
1. **용어 사전**: 전체 문서에서 추출된 모든 고유한 단어들의 집합
2. **포스팅 리스트**: 각 단어에 대해, 해당 단어가 나타나는 문서들의 id 목록과 부가 정보를 담고 있는 리스트

```
단어 (Term)  ->  [문서 ID, 문서 ID, ...]
`"cat"`         `->`  `[doc1, doc3, doc7]`
`"house"`       `->`  `[doc2, doc3]`
```

### 입력 데이터 형식
(Document_ID, Document_Content)
```
doc1, "the quick brown fox jumps over the lazy dog"
doc2, "a quick brown dog is quick"
doc3, "the lazy cat sat on the mat"
```

## 2. 인버티드 인덱스 생성 맵리듀스 알고리즘
**Map → Shuffle → Reduce**, 3단계를 통해 구현

**1) 맵 단계**
- 각 문서로부터 (단어, 문서ID) 쌍을 생성
- 입력: (doc_id, doc_content) 한 쌍
- 핵심 로직:
    1. **텍스트 정규화**: 문서 내용(doc_content)에서 검색에 불필요한 요소들을 제거하고 표준화
    2. **토큰화**: 정규화된 텍스트를 공백 기준으로 쪼개어 개별 단어(토큰)들로 분리
    3. **불용어 처리**: 검색어로서 의미가 없는 일반적인 단어들(ex. a, an, the, is, on)을 제거
    4. **key-value 출력**: 분리된 각 단어(Term)를 Key로, 해당 단어가 나온 문서 ID를 Value로 하여 (Key, Value) 쌍을 출력
- 출력: 문서에 포함된 단어의 수만큼 (term, doc_id) 쌍이 생성

**2) 셔플 및 정렬**
맵리듀스 프레임워크가 자동으로 처리하며, 맵 단계의 출력을 리듀스 단계의 입력으로 변환하는 과정

- 핵심로직: 
    모든 맵 노드에서 출력된 (term, doc_id) 쌍들을 **term을 기준으로 그룹화**
- 셔플 단계를 거친 후 데이터 구조"
    ```
    term (Key)	그룹화된 doc_id 리스트 (Value List)
    a	[doc2]
    brown	[doc1, doc2]
    cat	[doc3]
    dog	[doc1, doc2]
    fox	[doc1]  
    ```

**3) 리듀스 단계**
셔플 단계를 통해 그룹화된 데이터를 받아, 최종적인 형태의 **Postings List**를 생성
- 입력: (term, [doc_id_list])
- 핵심 로직:
    1. 입력으로 받은 doc_id 리스트에서 중복을 제거
    2. 중복이 제거된 doc_id 리스트를 정렬
    3. 최종적으로 정리된 포스팅 리스트를 생성

## 3. 인버티드 인덱스 흐름 예시
1) 입력 데이터
```
doc1: "The big brown fox"
doc2: "The big lazy dog"
doc3: "The small brown cat"
```

2) 맵 단계 출력
```
(The, doc1), (big, doc1), (brown, doc1), (fox, doc1)
(The, doc2), (big, doc2), (lazy, doc2), (dog, doc2)
(The, doc3), (small, doc3), (brown, doc3), (cat, doc3)
```

3) 리듀서 입력 (셔플 결과)
```
(The,   [doc1, doc2, doc3])
(big,   [doc1, doc2])
(brown, [doc1, doc3])
(cat,   [doc3])
(dog,   [doc2])
(fox,   [doc1])
(lazy,  [doc2])
(small, [doc3])
```

4) 최종 인버티드 인덱스
```
(The,   [doc1, doc2, doc3])
(big,   [doc1, doc2])
(brown, [doc1, doc3])
(cat,   [doc3])
(dog,   [doc2])
(fox,   [doc1])
(lazy,  [doc2])
(small, [doc3])
```
