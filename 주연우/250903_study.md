# 행렬 합 맵리듀스 알고리즘
## 1. 맵리듀스와 행렬 덧셈
### 행렬 덧셈
- 같은 크기의 두 행렬 A와 B가 주어졌을 때, 같은 위치에 있는 원소끼리 더하여 새로운 행렬 C를 만드는 연산

```C[i,j]=A[i,j]+B[i,j]```
각 원소 C[i, j]의 계산이 다른 위치의 원소 C[i', j'] 계산에 **전혀 영향을 주지 않는다**

### 맵리듀스 적용
"행렬의 각 원소 위치 (i, j)를 Key로 삼아, 같은 위치에 있는 모든 값들을 한 곳으로 모은 뒤(Shuffle), 모인 값들을 모두 더한다(Reduce)."

- 행렬 데이터를 맵리듀스가 읽을 수 있는 형태로 **변환**하는 것이 필요!

### 입력 데이터 표현 방식
맵리듀 작업의 입력은 일반적으로 key-value 형태의 텍스트 파일이다.  
두 행렬 A와 B는 각 원소의 정보를 담은 **텍스트 라인으로 변환** 되어야 한다.
```(Matrix_Name, Row_Index, Column_Index, Value)```
```
A: 1 2     B: 5 6
   3 4        7 8
```
두 행렬은 다음과 같은 텍스트 파일로 표현되어 맵리듀스 시스템에 입력됨.
```
A,0,0,1
A,0,1,2
A,1,0,3
A,1,1,4
B,0,0,5
B,0,1,6
B,1,0,7
B,1,1,8
```

## 2. 행렬 합 맵리듀스 알고리즘 상세 단계
### 1) Map Phase
맵 단계의 목적은 원본 입력 데이터를 읽어, 셔플 및 리듀스 단계에서 쉽게 그룹화할 수 있도록 **중간 Key-Value 쌍을 생성**하는 것
- 핵심 로직:
    1. 입력 줄을 쉼표(,)로 파싱하여 각 정보를 분리한다.
    2. 행 인덱스 i와 열 인덱스 j를 조합하여 Key를 생성합니다. 이 Key는 (i, j) 형태의 복합 Key가 된다.
    3. 원소의 값을 value로 지정
- 출력: (key, value) 쌍, ((i, j), value) 형태의 중간 데이터를 출력
입력 라인	출력 Key (i, j)	출력 Value
```
A,0,0,1	(0,0)	1
A,0,1,2	(0,1)	2
A,1,0,3	(1,0)	3
A,1,1,4	(1,1)	4
B,0,0,5	(0,0)	5
B,0,1,6	(0,1)	6
B,1,0,7	(1,0)	7
B,1,1,8	(1,1)	8
```

- 맵 단계에서는 단순히 입력 데이터의 형식을 바꾸어 재구성하는 역할만 수행

### 2) 셔플 및 정렬 단계
맵리듀스 프레임워크가 **내부적으로 자동 처리**하는 과정  
- 핵심로직: 맵 단계에서 출력된 모든 (Key, Value) 쌍들을 Key를 기준으로 그룹화한다다 . 즉, 동일한 Key를 가진 모든 Value들을 모아서 하나의 리스트로 만든다.
- 맵 단계의 출력이 셔플 단계를 거친 후의 데이터 구조:
```
Key (i, j)	그룹화된 Value 리스트
(0,0)	    [1, 5]
(0,1)	    [2, 6]
(1,0)	    [3, 7]
(1,1)	    [4, 8]
```

### 3) Reduce Phase
셔플 단계를 통해 그룹화된 데이터들을 받아 **실제 집계 연산을 수행**하여 최종 결과를 도출

- 핵심 로직:
    1. 입력으로 받은 Value 리스트 [Value1, Value2, ...]의 모든 원소를 순회하며 더한다.
    2. 최종 합산된 값(Sum)을 계산
- 출력: (Key, Sum) 쌍, 즉 ( (i, j), Sum ) 형태의 최종 결과를 출력
